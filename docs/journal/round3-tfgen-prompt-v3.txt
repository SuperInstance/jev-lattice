  - Type-specific safe defaults in change.after:

  - Then, for each RISK below, flip rnd() < 0.45; if true, PLANT it into one resource chosen by Math.floor(rnd() * candidates.length) among resources of the right type:
      destroy:     set actions of any resource to ["delete"] (or ["delete","create"] if rnd() < 0.5)
      ssh_public:  a security group: push { from_port: 22, to_port: 22, protocol: "tcp", cidr_blocks: ["0.0.0.0/0"] } (or, if rnd() < 0.3, { from_port: 0, to_port: 65535, ... "0.0.0.0/0" })

      db_unprot:   a db instance: deletion_protection = false
