Context: "JEV lattice" is a library for software decisions. Yes/no QUESTION nodes have deterministic gates:
BINARY (one proof >= threshold) or COORDINATED (k independent proofs). Verdicts: GO, OPEN, REFUTED, CONFLICT.
Proof sources and what we measured:
- TypeSafe Jev: calibrated yes/no (Noul), Choice and Score answers on a JSON "state"; ~100ms; hundreds of questions per call; 0 wrong GOs in 600+ config questions; abstains (stays OPEN) instead of erring on counting questions; not bit-deterministic, so answers are cached by state hash.
- MiniMax LLM: slow (5-40s), good at decomposing questions and writing small JS predicates.
- Compiled predicates: model-written code validated against confident Jev labels; safe only in "refute-only" mode (code may say no; a yes needs Jev).
- Cloudflare: Durable Object per lattice, alarms for idle re-verification, Workers AI small model (overconfident), Dynamic Worker isolates for running predicates, drift detection by content hash.
